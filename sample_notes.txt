Introduction to Python and Artificial Intelligence

1. Python Basics

Python is a high-level programming language used for web development,
data analysis, automation, and artificial intelligence. Variables
store values, and functions group reusable blocks of code.

2. Artificial Intelligence

Artificial intelligence refers to computer systems that perform
tasks involving reasoning, prediction, language understanding,
and decision-making.

Machine learning is a branch of AI in which models learn patterns
from data. Deep learning uses neural networks with multiple layers
to learn complex representations.

3. Text Embeddings

Text embeddings are numerical representations of text. They map
words, sentences, or documents into vectors that capture semantic
information.

Texts with similar meanings often have nearby vector representations,
allowing semantic search to find relevant content even when exact
keywords differ.

4. Vector Databases

A vector database stores and searches vector embeddings. ChromaDB
can store embeddings alongside document text and metadata.

Metadata can identify the source document and the page or section
from which a passage was extracted.

5. Retrieval-Augmented Generation

Retrieval-Augmented Generation, or RAG, combines document retrieval
with language generation.

A RAG system first retrieves relevant passages from a knowledge
source. It then provides those passages and the user's question
to a language model.

RAG can improve factual grounding by supplying relevant evidence.
However, the system must retrieve useful passages and generate
answers faithfully.

6. Text Splitting

Text splitting divides a long document into smaller chunks.
Smaller chunks make it easier to retrieve relevant sections.

Chunk overlap preserves some text from neighboring chunks. This
helps maintain context when a concept crosses a chunk boundary.

7. AI Learning Assistant

An AI learning assistant can answer questions about course materials,
explain concepts, and provide source references.

A career assistant can also search for internships and entry-level
jobs that match a student's skills and topics.

A tool-using AI agent can select different tools depending on whether
a student asks a learning question, a career question, or both.
